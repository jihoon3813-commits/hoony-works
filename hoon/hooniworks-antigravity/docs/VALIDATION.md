# 전달본 검증 기록

검증 기준일: 2026-11-03 (한국 시간). 배포 버전 3의 소스를 변경 없이 전달한다.

## 이번 ZIP에서 실행한 검사

- `npm run check`: app.js, enhancements.js, hooniworks.js, 로컬 실행 서버의 JavaScript 문법 검사 통과.
- `npm test`: 기존 데이터 이전, 원본 이미지 ID 보존, 상품별 캠페인·사진·템플릿·계정·게시 기록 분리, 범용 캠페인 생성, 공통 예산, 새로 로드한 상태의 복원, 상품별 초기화, 저장 용량 오류 시 복구, 손상된 데이터 덮어쓰기 방지 검사 통과.
- 로컬 실행 서버 시작 후 HTML/JS/CSS/이미지 총 10개 경로의 비어 있지 않은 HTTP 200 응답 확인. 검증 후 서버 종료.
- `dist/` 및 `tests/` 파일을 배포 커밋의 파일 바이트와 비교해 일치 확인.
- 개발 전달 ZIP의 CRC와 SOURCE_MANIFEST.json의 파일별 SHA-256 일치 확인.

## 동일 소스로 앞서 확인한 브라우저 동작

- 새 서비스 상품 작업실과 첫 캠페인 생성.
- 새 상품의 채널 계정을 저장하고, 120pie로 전환했을 때 기존 계정·캠페인·자료 유지.
- 새 상품의 템플릿 이름과 문구에 120 전용 메뉴 표현이 섞이지 않음.
- 새로고침 후 상품 선택과 저장 기록 복원.
- 390px iframe에서 대시보드·제작실·게시 준비 화면의 content/scroll width가 모두 375px로 가로 넘침 없음.

## 남은 검증

- 실제 모바일 단말에서의 터치·파일 선택·다운로드 동작.
- 사용자 브라우저에서 콘텐츠 PNG/ZIP의 실제 파일 다운로드 완료. 이전 시안 검증에서는 ZIP 구성·CRC는 통과했으나 자동화 브라우저의 다운로드 완료 이벤트는 확인하지 못했다.
- 실서비스 로그인·DB·파일 저장·생성 API·MP4·OAuth·자동 게시 검증. 해당 기능은 현재 미구현이다.

이 기록의 **개발 전달 ZIP 무결성 검사**와 앱 안에서 만드는 **콘텐츠 ZIP 다운로드 검수**는 서로 다른 검사이다.
