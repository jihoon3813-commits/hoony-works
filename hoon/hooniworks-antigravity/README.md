# 후니웍스 · HooniWorks — 안티그래비티 개발 패키지

여러 상품·브랜드의 마케팅 콘텐츠를 한곳에서 관리하는 프로그램입니다. **120pie&coffee는 첫 번째 상품**이며, 새 상품을 추가하면 해당 상품의 독립된 작업실이 만들어집니다.

기준: 2026-11-03 / 배포 버전 3 / 커밋 `8a03258839929a857dbdedf9cbd24d951f074c13`.

## 바로 시작하기

1. ZIP을 풀고 `hooniworks-antigravity` 폴더를 안티그래비티에서 엽니다.
2. **`00_ANTIGRAVITY_START.md` 내용을 안티그래비티 대화창에 전달합니다.**
3. Node.js 18 이상 환경에서 다음을 실행합니다. 외부 패키지 설치는 필요 없습니다.

```bash
npm start
```

4. `http://127.0.0.1:3000`을 엽니다. HTML 파일 더블클릭 대신 로컬 서버로 확인하세요.
5. 코드 변경 후 검사합니다.

```bash
npm run check
npm test
```

현재 서버는 정적 화면을 로컬에서 보여주는 용도입니다. 데이터베이스·생성 API·SNS 게시 서버는 실행되지 않습니다. Google Fonts를 불러올 수 없으면 시스템 글꼴을 사용합니다.

## 현재 구현된 기능

| 구분 | 작동 범위 |
|---|---|
| 후니웍스 공통 화면 | 전체 대시보드, 상품 목록·검색, 상품 추가·전환, 공통 API 사용 설정 |
| 상품별 작업실 | 이름·분류·색상·고객·설명, 캠페인, 이미지, 내 템플릿, 채널 정보, 게시 기록 분리 |
| 120pie | 기존 샘플 캠페인과 제품 사진 유지, 기존 브라우저 데이터 이전 |
| 새 상품 | 빈 작업실로 시작, 120pie 문구·사진·계정 자동 복제 없음 |
| 콘텐츠 제작 | 브리프·카드 제목·채널별 본문 편집, 이미지 미리보기, 장면표, PNG·TXT·콘텐츠 ZIP 구성 |
| 디자인 출발점 | 새 콘셉트 기획 / 레퍼런스 활용 / 저장 템플릿 활용 선택 및 저장 |
| 자료·디자인 | 이미지 원본 업로드·브라우저 보관, 실제 사진·참고·로고 구분, 템플릿 9종 및 추가·편집 |
| 채널·게시 준비 | 홈페이지·SNS 주소와 계정명, 준비 기록, 수동 게시 URL 기록, 관리자 이동 |

**디자인 출발점을 선택하는 UI와 저장 기능은 구현되어 있지만, 새로운 콘셉트 3안을 실제로 생성하는 기능은 아직 없습니다.** 현재 디자인은 편집용 구성 예시입니다. API 미연결 상태에서 생성·인증·게시가 완료된 것처럼 표시하지 않습니다.

## 앞으로 개발할 기능

- 로그인, 서버 데이터베이스, 원본 파일 저장, 상품별 접근 권한
- 템플릿에 제한되지 않는 콘셉트 3안 기획과 실제 이미지 생성
- 제품·로고 원본 보존, 편집 가능한 텍스트·배경·사진 레이어
- 장면별 영상 생성, 자막·음성·음악 합성, 실제 MP4 출력
- 서버의 안전한 API 키 관리, 예산·작업 큐·중복 실행 방지
- 채널별 OAuth, 게시 전 검토, 공식 API를 통한 게시 결과 확인

## 데이터와 배포 범위

이 ZIP에는 코드에 포함된 기본 이미지와 샘플만 들어 있습니다. 실제 사이트 이용자가 브라우저에 저장한 사진·설정·캠페인이나 QA용 테스트 상품은 포함하지 않습니다. 기존 Sites의 Git 인증정보·호스팅 설정·실제 API 키도 포함하지 않습니다.

사이트 도메인과 `127.0.0.1`은 다른 저장 공간이므로, 배포 사이트의 브라우저 자료가 로컬 실행 화면으로 자동 이동하지 않습니다. 브라우저 저장 데이터는 서버 로그인·백업·여러 기기 동기화를 대신하지 않습니다. 현재 코드의 이전 방식과 서버 가져오기 과제는 아키텍처 문서를 확인하세요.

독립적인 Git 저장소와 배포 환경을 안티그래비티에서 설정하면 됩니다. 실행 파일의 스크립트 순서를 임의로 바꾸지 마세요.
